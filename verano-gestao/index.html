Política de Privacidade

Aplicativo: Verano Gestão

Última atualização: 18 de maio de 2026

Esta Política de Privacidade explica como o aplicativo Verano Gestão coleta, usa, armazena e protege informações fornecidas pelos usuários.

O Verano Gestão é um aplicativo desenvolvido pela Verano Apps para ajudar profissionais autônomos e pequenos negócios a organizarem clientes, serviços, agendamentos, pagamentos e informações financeiras operacionais em um só lugar.

Ao utilizar o Verano Gestão, você concorda com os termos desta Política de Privacidade.

1. Quem somos

O Verano Gestão é desenvolvido e mantido pela Verano Apps.

Contato:
veranoapps@gmail.com

Site:
veranoapps.com

2. Quais dados coletamos

O Verano Gestão coleta apenas os dados necessários para o funcionamento do aplicativo.

Podemos coletar e armazenar os seguintes tipos de informações:

2.1. Dados da conta

Quando você cria uma conta ou faz login no aplicativo, podemos coletar:

  • nome;
  • e-mail;
  • telefone, se informado;
  • nome do negócio, se informado;
  • identificador de usuário gerado pelo sistema de autenticação.

Esses dados são usados para identificar sua conta, permitir login e manter seus dados separados dos dados de outros usuários.

2.2. Dados de autenticação

O Verano Gestão utiliza Firebase Authentication para permitir login por e-mail e senha e/ou login com conta Google.

Quando você usa esses métodos de login, os dados necessários para autenticação podem ser processados pelo Firebase/Google, como:

  • e-mail;
  • identificador único da conta;
  • informações básicas associadas ao login, quando aplicável.

A senha do usuário não é armazenada diretamente pela Verano Apps.

2.3. Dados cadastrados pelo usuário

Durante o uso do aplicativo, você pode cadastrar informações como:

  • clientes;
  • telefones de clientes;
  • observações sobre clientes;
  • serviços oferecidos;
  • duração e valor de serviços;
  • agendamentos;
  • datas e horários;
  • status de agendamentos;
  • informações de pagamento;
  • valores previstos e recebidos;
  • observações inseridas pelo próprio usuário;
  • informações de vale-presente, quando esse recurso estiver ativado.

Essas informações são fornecidas voluntariamente pelo usuário e são usadas para exibir e organizar as funcionalidades do aplicativo.

2.4. Dados financeiros operacionais

O Verano Gestão permite que o usuário registre valores relacionados a serviços, agendamentos e pagamentos.

Esses dados são usados apenas para controle operacional dentro do próprio app, como:

  • valores de serviços;
  • valores previstos;
  • valores recebidos;
  • status de pagamento;
  • resumo financeiro por período.

O Verano Gestão não realiza transações financeiras, não processa pagamentos, não concede crédito, não oferece empréstimos, não faz investimentos e não funciona como banco, carteira digital ou instituição financeira.

2.5. Dados técnicos

Podemos coletar dados técnicos necessários para funcionamento, segurança e autenticação do aplicativo, como:

  • identificadores técnicos gerados pelo Firebase;
  • informações necessárias para manter a sessão do usuário;
  • dados básicos de funcionamento do app.

No momento, o Verano Gestão não utiliza dados para publicidade personalizada.

3. Como usamos os dados

Usamos os dados coletados para:

  • permitir criação e acesso à conta;
  • autenticar o usuário;
  • separar os dados de cada usuário;
  • salvar e exibir clientes, serviços e agendamentos;
  • calcular e exibir informações financeiras cadastradas pelo usuário;
  • permitir recursos como vale-presente, notificações e lembretes;
  • melhorar a organização da rotina do usuário;
  • manter a segurança e o funcionamento do aplicativo;
  • prestar suporte quando solicitado pelo usuário.

Não vendemos dados pessoais dos usuários.

4. Onde os dados são armazenados

O Verano Gestão utiliza serviços do Firebase, fornecidos pelo Google, para autenticação e armazenamento de dados.

Os principais serviços utilizados são:

  • Firebase Authentication, para login e autenticação;
  • Cloud Firestore, para armazenamento dos dados do aplicativo.

Os dados do aplicativo são armazenados em infraestrutura do Google/Firebase. O Firebase informa que alguns serviços podem processar e armazenar dados em locais diferentes, conforme o serviço utilizado. O Firebase Authentication, por exemplo, é processado em data centers nos Estados Unidos.

5. Segurança dos dados

Adotamos medidas para proteger os dados dos usuários.

O Verano Gestão usa autenticação de usuário e regras de segurança no Cloud Firestore para que cada usuário acesse apenas os dados associados à sua própria conta.

Além disso, o Cloud Firestore utiliza criptografia dos dados antes de serem gravados em disco, conforme a infraestrutura do Google Cloud/Firebase.

Apesar das medidas de segurança, nenhum sistema é completamente imune a falhas. Por isso, também recomendamos que o usuário proteja sua conta, utilize senha segura e não compartilhe seus dados de acesso.

6. Compartilhamento de dados

A Verano Apps não vende dados pessoais dos usuários.

Podemos compartilhar ou processar dados apenas quando necessário para:

  • funcionamento do aplicativo por meio de provedores de infraestrutura, como Google/Firebase;
  • cumprimento de obrigações legais;
  • proteção contra fraude, abuso ou uso indevido do aplicativo;
  • atendimento a solicitações do próprio usuário.

O uso de serviços do Google/Firebase significa que determinados dados podem ser processados pela infraestrutura do Google conforme os termos e políticas desses serviços.

7. Dados de clientes cadastrados pelo usuário

O usuário é responsável pelas informações que cadastra no aplicativo sobre seus próprios clientes, serviços e agendamentos.

Ao cadastrar dados de terceiros, como nome e telefone de clientes, o usuário declara que possui autorização ou base adequada para registrar essas informações em seu próprio controle operacional.

A Verano Apps apenas fornece a ferramenta para organização desses dados.

8. Notificações

O Verano Gestão pode utilizar notificações e lembretes locais para ajudar o usuário a acompanhar sua agenda e rotina.

As notificações podem estar relacionadas, por exemplo, a:

  • agendamentos do dia;
  • lembretes de agenda;
  • pagamentos pendentes;
  • avisos internos do app.

O usuário pode ativar ou desativar notificações nas configurações do aplicativo ou nas configurações do próprio dispositivo.

9. Retenção dos dados

Mantemos os dados enquanto a conta do usuário estiver ativa ou enquanto forem necessários para o funcionamento do aplicativo.

O usuário pode solicitar a exclusão de seus dados entrando em contato pelo e-mail:

veranoapps@gmail.com

Após uma solicitação de exclusão, os dados associados à conta poderão ser removidos, salvo quando houver necessidade de retenção por obrigação legal, segurança, prevenção de fraude ou resolução de problemas técnicos.

10. Direitos do usuário

O usuário pode solicitar:

  • acesso aos dados associados à sua conta;
  • correção de dados incorretos;
  • exclusão dos dados;
  • informações sobre como seus dados são utilizados;
  • revogação de consentimentos, quando aplicável.

Para exercer esses direitos, entre em contato pelo e-mail:

veranoapps@gmail.com

11. Crianças e adolescentes

O Verano Gestão não é destinado a crianças.

O aplicativo foi desenvolvido para profissionais autônomos, prestadores de serviço e pequenos negócios.

Não coletamos intencionalmente dados de crianças.

12. Transferência internacional de dados

Como o Verano Gestão utiliza serviços do Firebase/Google, os dados podem ser processados ou armazenados em servidores localizados fora do país do usuário, conforme a infraestrutura e os termos dos serviços utilizados.

Ao utilizar o aplicativo, o usuário entende que seus dados podem ser tratados em outros países, sempre com as medidas de segurança aplicáveis aos serviços utilizados.

13. Alterações nesta Política de Privacidade

Esta Política de Privacidade pode ser atualizada periodicamente para refletir mudanças no aplicativo, nos serviços utilizados ou em requisitos legais.

Quando houver alterações relevantes, a data de atualização será modificada nesta página.

Recomendamos que o usuário consulte esta página periodicamente.
